# Credits

BioPHP is a modernization of code and ideas originally published on
[biophp.org](http://biophp.org/), a collaborative wiki for PHP bioinformatics
code founded in 2005. This file lists everyone credited by name on that site,
along with the related projects it links to. Sources are cited so entries can
be re-verified as the upstream site changes.

## Founder

- **Dr. Joseba Bikandi** — Department of Immunology, Microbiology and
  Parasitology, Faculty of Pharmacy, University of the Basque Country,
  Vitoria-Gasteiz, Spain. Started biophp.org in December 2005, building on PHP
  scripts he had developed for simulating molecular biology techniques,
  originally hosted at [insilico.ehu.eus](http://insilico.ehu.eus).
  (Source: biophp.org `info.html`)

## Original GenePHP author

- **Serge Gregorio, Jr.** (S. Gregorio) — conceived and wrote GenePHP, the
  BioPerl-to-PHP rewrite that biophp.org's `Sequence`/`Sequence Database`
  classes descend from. Credited in `info.html` as GenePHP's originator, and
  named directly in the header comments of several files this repository's
  `Legacy/` directory preserves: `entrez.inc.php`, `genome.inc.php`,
  `hgbase.inc.php`, `kegg.inc.php`, `lit.inc.php`, and `pdb.inc.php`.
  (Sources: biophp.org `info.html`; `Legacy/*.inc.php` headers;
  http://genephp.sourceforge.net)
